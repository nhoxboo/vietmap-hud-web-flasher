Nạp Firmware Cho ESP32 Trực Tiếp Trên Web

Sử dụng Google Chrome / Microsoft Edge kết nối cáp USB với ESP32 để nạp chương trình chỉ bằng 1 cú nhấp chuột.

Đang chọn

ESP32-2432S024

Màn hình chữ nhật 2.4" / 2.8" (CYD Cheap Yellow Display)

  • Driver LCD: ILI9341 SPI (320x240 ngang)
  • Tích hợp còi Buzzer GPIO 26 & Cảm biến quang trở LDR
  • Đã tối ưu bỏ OBD, phản hồi cực nhanh 4Hz
Đang chọn

ESP32-2424S012

Màn hình tròn 1.28" GC9A01 (Round Display)

  • Driver LCD: GC9A01 SPI (240x240 tròn)
  • Giao diện mặt đồng hồ thể thao Taplo siêu sang
  • Kích thước siêu nhỏ gọn, phù hợp gắn taplo/xe máy
Thiết bị: ESP32-2432S024 (CYD 2.4")

Sẵn Sàng Nạp Vào Board

Cắm cáp USB nối ESP32 với máy tính. Nhấn nút CONNECT bên dưới, chọn cổng COM (CH340 / CP2102) để trình duyệt tự động xóa Flash và nạp toàn bộ Bootloader, Partition Table và Firmware mới.

Trình duyệt chưa hỗ trợ Web Serial. Vui lòng dùng Chrome hoặc Edge trên máy tính!

Baudrate tự động: 921600 / 115200

Cách Kết Nối Với App Vietmap Live / Mapviet Trên Điện Thoại

  1. Bật Bluetooth trên điện thoại iPhone hoặc Android.
  2. Cấp nguồn cho mạch ESP32 qua cổng Type-C / sạc tẩu trên xe hơi. Màn hình khởi động sẽ hiện chữ VIETMAP HUD và báo BLE Ready.
  3. Mở ứng dụng Vietmap Live (hoặc ứng dụng Mapviet), vào mục Cài đặt → Kết nối HUD → Chọn thiết bị VIETMAP_HUD.
  4. Khi kết nối thành công, màn hình sẽ tự động hiển thị tốc độ, giới hạn tốc độ và hướng dẫn chỉ đường thời gian thực!
